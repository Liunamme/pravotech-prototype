# ПравоТех — структура приложения для макета

Полный инвентарь интерфейса, выгруженный из реального кода. Назначение — основа для
макета в Claude Design: все экраны, зоны, компоненты, кнопки, меню, состояния и токены.

Проект: B2B-платформа, где AI-агент выполняет работу юриста; юрист подтверждает / изменяет /
отклоняет предложения агента. Два уровня, одна грамматика, всё вокруг диалога и карточек действий.

---

## 1. Карта навигации (роуты)

| Роут | Экран |
|---|---|
| `/#/today` | Уровень 1 — «Сегодня» (вход в платформу) |
| `/#/w/:workspaceId` | Уровень 2 — рабочее пространство (без выбранного треда → приглашение) |
| `/#/w/:workspaceId/t/:threadId` | Пространство с открытым разговором |
| `/#/w/:workspaceId/tab/:tabId` | Пространство с активной вкладкой контекста |
| `/#/settings` | Настройки |
| `/#/settings/kitchen-sink` | Витрина всех UI-компонентов (для отладки/дизайна) |
| `/#/*` | 404 |

Два рабочих пространства: `obligations` («Обязательства по договорам»), `litigation` («Судебные дела»).

## 3. Экран «Сегодня» (уровень 1)

Три ресайзящиеся колонки (разделители перетаскиваются мышью и клавиатурой):

```
┌──────┬─────────────┬──────────────────────────┬────────────────────────┐
│ Рейка│ Навигация   │      Дневной чат          │  Плашка «Ближайшее»    │
│      │ дня (240px) │      (flex, центр)        │  ────────────────────  │
│      │             │                           │  [Очередь 8]│[Сроки]   │
│      │  Сегодня    │  ПравоТех · дата          │  ────────────────────  │
│      │  ─────────  │  Утренний дайджест        │  P0 · Срочно      (2)  │
│      │  Простр-ва: │  (стриминг по токенам)    │  ┌──────────────────┐  │
│      │  Обязат. 4  │  ¹ ² ³ ⁴ (цитаты)         │  │  Карточка P0     │  │
│      │  Дела    4  │                           │  │  ...             │  │
│      │             │  [textarea] [Отправить/   │  └──────────────────┘  │
│      │  [лоток]    │             Остановить]   │  ...                   │
└──────┴─────────────┴──────────────────────────┴────────────────────────┘
```

### Колонка 1 — Навигация дня (`DayNav`), 240px
- Заголовок с текущей датой («Суббота, 25 июля»)
- Пункт «Сегодня» (активный)
- Секция «Рабочие пространства»: список с иконкой, названием и **счётчиком открытых карточек**
- Внизу — индикатор лотка фоновых задач

### Колонка 2 — Дневной чат (`ChatView`, центр, flex)
- **Шапка треда:** заголовок «Сегодня» + бейдж статуса («Активен»)
- **Лента сообщений** (`MessageList`) — прокрутка:
  - сообщение агента: аватар-иконка в кружке + имя «ПравоТех» + время
  - блоки текста, стриминг с мигающим курсором
  - **чипы-цитаты** ¹²³ в конце абзаца (кликабельны → инспектор)
  - таблицы, превью документов, карточки прямо в ленте
  - реплики юриста — выровнены вправо, без «пузырей»
- **Композер** (`Composer`) внизу:
  - автоувеличивающаяся `textarea` («Спросите агента или опишите задачу…»)
  - кнопка **«Отправить»** (иконка) → во время стриминга становится **«Остановить»**
  - `Enter` — отправка, `Shift+Enter` — перенос
- Кнопка **«Вниз»** с бейджем новых сообщений (когда прокручено вверх)

### Колонка 3 — Очередь и сроки (`RightPanel`), 360px
- **Плашка «Ближайшее»** (`UpcomingBanner`) — постоянно сверху: ближайший срок с обратным отсчётом + счётчик P0
- **Сегментированный переключатель** «Очередь · Сроки» (со счётчиками)
- **Сегмент «Очередь»** (`CardQueue`) — карточки действий со всех пространств
- **Сегмент «Сроки»** (`DeadlineTimeline`) — таймлайн ближайших дедлайнов

### Колонка 1 — Сайдбар пространства (`WorkspaceSidebar`)
**Верхняя часть — список разговоров-задач:**
- Заголовок «РАЗГОВОРЫ» + кнопка **[+]** (новый разговор)
- Список тредов: название, индикатор непрочитанного (точка), активный подсвечен
- Пустое состояние: «Пока ни одного разговора» + кнопка «Новый разговор»

**Нижняя часть — вкладки контекста** (`Tabs`, зависят от пространства):

## 5. Инспектор документа (оверлей, `DocumentInspector`)

Слайд-овер справа, ширина 520px, поверх правой колонки. Чат/очередь остаются видны.
Открывается кликом по любой цитате (`CitationChip`) или ссылке на документ.

```
                          ┌────────────────────────────────┐
                          │ ДОГОВОР                    [✕]  │  ← тип + закрыть
                          │ Договор аренды №44-АР от ...    │  ← название
                          │ Стороны   ООО «...» · ООО «...» │
                          │ Дата      12.03.2024           │  ← мета-шапка
                          │ Вид       Договор аренды       │
                          │ Статус    Действует            │
                          │ [Открыть полностью]            │
                          │ ──────────────────────────────  │
                          │ Раздел 7. Срок действия         │  ← тело (serif)
                          │  7.2  Если ни одна из Сторон... │
                          │ ▓7.3  Уведомление ...  ▓        │  ← подсвеченный якорь
                          └────────────────────────────────┘
```

Элементы:
- **Кнопка закрытия [✕]** (icon-only, `aria-label`)
- **Мета-шапка:** тип, название, стороны, дата, вид/номер, статус
- **Кнопка «Открыть полностью»**
- **Тело документа** (`DocumentViewer`) — serif-шрифт (Source Serif 4), номера пунктов на полях, блоки: заголовки, пункты (clause), абзацы, таблицы
- **Подсветка якоря** (`HighlightAnchor`) — нужный пункт прокручен в центр, подсвечен с плавным затуханием
- Закрытие: `✕`, `Esc`, клик по чату
- Состояние отражается в URL: `?doc=..&anchor=..` (ссылка шарится)

## 6. Фоновый лоток задач (оверлей, `BackgroundTaskTray`)

Плавающий индикатор у рейки внизу со счётчиком активных задач. Клик → Popover со списком.

Каждая задача в поповере:
- Название («Подготовка позиции по делу А40-118742»)
- **Шаги** со ступенчатым прогрессом (pending / active / done / failed)
- Полоса прогресса + счётчик «7 из 12» (моноширинные цифры)
- По завершении — кнопка **«Открыть результат»**
- Кнопка **закрыть/скрыть** задачу

## 8. Анатомия карточки действия (главный компонент)

```
┌─────────────────────────────────────────────────┐
│ [P0] ⚖ Уведомление  [Обязательства]  Завтра, 26 │  ← приоритет·тип·пространство·срок
│                                                  │
│ Направить отказ от пролонгации по №44-АР        │  ← заголовок (глагол)
│ Срок направления отказа истекает завтра —        │  ← суть (последствие)
│ договор иначе продлится на 11 месяцев.           │
│                                                  │
│ Договор №44-АР                                   │  ← привязка
│ [📄 п. 7.3] [📄 п. 7.2]                          │  ← источники (кликабельны)
│ Контрагент  ООО «Прайм Ритейл»                   │  ← тело типа (специфика)
│ Если не уведомить, продлится до  13.09.2026      │
│ ┌──────────────────────────────────────────┐    │
│ │ Уведомляем о намерении не продлевать...   │    │  ← проект текста
│ └──────────────────────────────────────────┘    │
│ → Показать в чате                                │
│                                                  │
│ [ Подтвердить ]  [ Изменить ]  [ Отклонить ]     │  ← три исхода
└─────────────────────────────────────────────────┘
```

**Плотность по приоритету:** P0 — развёрнута сразу; P1 — свёрнута, суть видна; P2/P3 — только заголовок.
**Три исхода:**
- **Подтвердить** (primary) → исполнение со шагами → undo-тост 6с
- **Изменить** → раскрытие формы на месте, подсветка правок → «Сохранить и подтвердить»/«Отмена»
- **Отклонить** (ghost, слабее)
- Для необратимых (`filing_deadline`) — вместо undo диалог подтверждения

**Типы карточек:**
| Пространство | Типы |
|---|---|
| obligations | `renewal_notice` · `obligation_breach` · `payment_due` |
| litigation | `hearing_prep` · `evidence_request` · `filing_deadline` (destructive) |
