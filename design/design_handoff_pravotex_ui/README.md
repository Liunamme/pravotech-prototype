# Хендофф: интерфейс ПравоТех (десктоп / планшет / мобильный)

## Что это

Дизайн-макет агентского юридического интерфейса ПравоТех: рабочий день юриста строится вокруг
диалога с агентом и «Очереди решений» (P0–P3), плюс два пространства — «Обязательства» (договоры,
сроки, автопролонгации) и «Дела» (судебные дела, заседания, процессуальные сроки).

## О файлах в этом бандле

Файлы в `design/` — **дизайн-референс, написанный на HTML/JS**. Это прототипы, показывающие
внешний вид и поведение, а **не production-код для копирования**. Задача — воспроизвести эти
макеты в текущей кодовой базе (`PravoTexTZ`: Next.js + React + Tailwind) её собственными
средствами: компонентами, токенами, роутингом. HTML брать как эталон верстки, разметку — не
переносить дословно.

Файлы:

- `design/pravotex-desktop.dc.html` — десктоп 1440×900 (полный интерфейс, обе темы).
- `design/pravotex-adaptive.dc.html` — тот же интерфейс в раскладках `tablet` (834×1194) и
  `mobile` (402×874); переключается пропом `layout`.
- `design/pravotex-showcase.dc.html` — витрина: три макета в мокапах MacBook Pro / iPad Pro /
  iPhone 17 Pro. Только презентация, к продукту отношения не имеет.
- `design/support.js` — рантайм превью. **В продукт не переносить.**
- `context/tech-task.md`, `context/APP-STRUCTURE.md` — исходное ТЗ и выгрузка структуры приложения.

Открыть локально: любой файл из `design/` можно открыть прямо в браузере (двойным щелчком).

## Фиделити

**Hi-fi.** Цвета, типографика, отступы, скругления, состояния и микроанимации финальные —
воспроизводить попиксельно, но существующими библиотеками кодовой базы.

### Типографика

Golos Text (Google Fonts), веса 400/500/600/700. Базовый размер 13px.
Заголовок раздела 15–16px/600 · тело чата 13.5px/1.62 · подписи и метки 10.5–11.5px ·

### Геометрия и эффекты

Скругления: рабочая область 22px · карточки 14–16px · пилюли/теги 999px · кнопки 11–13px ·
иконки-квадраты 12–15px. Отступы кратны 2 (6/8/10/12/14/20/24).
«Стекло»: `background: var(--pt-overlay)` + `backdrop-filter: var(--pt-overlay-blur)` +
`1px solid var(--pt-overlay-line)` + `inset 0 1px 0 rgba(255,255,255,.18)` (световой кант сверху).
Фон приложения: три радиальных пятна `--pt-bloom1..3` под контентом, `pointer-events: none`.
Скроллбары скрыты, у прокручиваемых лент — маска затухания по краям.

## Экраны и раскладки

### Десктоп 1440×900 (`pravotex-desktop.dc.html`)

Слева направо:

1. **Рейка 56px** — иконки разделов (Сегодня / Обязательства / Дела), внизу: фоновые задачи
   (с бейджем-счётчиком), переключатель темы, настройки. Активный раздел — залитая
   `--pt-accent-soft` плашка 15px.
2. **Сайдбар 232px** — логотип «право(тех)»; на «Сегодня»: дата, кнопка «Сегодня» (заливка
   акцентом), заголовок «РАБОЧИЕ ПРОСТРАНСТВА» и строки пространств со счётчиками-пилюлями;
   в пространстве: «ДИАЛОГИ» с «+», список диалогов с цветной точкой статуса, вкладки
   «Договоры / Обязательства» (в делах — «Дела / Заседания») и карточки документов. Внизу —
   аккаунт (аватар-инициалы, имя, роль).
3. **Чат** — шапка (заголовок + статус «Активен»), лента сообщений (пользователь — пузырь
   акцентом справа; агент — аватар «П», имя, время, абзацы, сноски-цитаты, карточки задач с
   тегом приоритета), композер: поле «Спросите агента или опишите задачу…» + круглая кнопка
   отправки 34px.
4. **Инспектор ~360px** — вкладки «Очередь / Сроки»; группы «P0 · СРОЧНО», «P1 · НА ЭТОЙ НЕДЕЛЕ»,
   «P2 · ПОЗЖЕ» (заголовок капсом, линия, счётчик справа); карточки решений: тег приоритета,
   тип, срок (у P0 — красным), заголовок, пояснение, ссылки на пункты договора, черновик
   документа в рамке, кнопки «Подтвердить» (акцент) / «Изменить» / «Отклонить» (текстовая).
   У P0 — акцентная красная обводка и halo. «Сроки» — заголовки-даты капсом с линией и карточки
   событий.

Оверлеи: фоновые задачи и настройки — стеклянные плашки у рейки; тост «Подтверждено» с «Отменить».

### Планшет 834×1194 (`layout="tablet"`)

Рейка + сайдбар как на десктопе. Правая часть — вкладки «Диалог · Сроки · Очередь»;
очередь открывается оверлеем поверх рабочей области (сайдбар не перекрывает) с крестиком.

### Мобильный 402×874 (`layout="mobile"`)

Шапка: логотип, кнопка диалогов, фоновые задачи с бейджем. Ниже — заголовок раздела и
горизонтальная лента вкладок раздела («Диалог · Договоры · Обяз.» / «Дела · Засед.», «Сроки»),
справа за разделителем — «Очередь» с бейджем. Таб-бар снизу: Сегодня · Обязательства · Дела ·
Настройки (44px+ хит-зоны). Очередь — полноценный раздел (не попап), настройки — bottom sheet.

## Взаимодействия

- Переключение разделов, диалогов, вкладок документов и вкладок инспектора.
- Ввод в композер + отправка: сообщение пользователя добавляется сразу, ответ агента
  «печатается» посимвольно (стриминг).
- Чипы навыков на пустом экране чата запускают соответствующий сценарий.
- «Подтвердить» на карточке очереди: карточка исчезает, счётчик уменьшается, появляется тост
  «Подтверждено» с «Отменить» (возврат состояния).
- Переключение темы — мгновенная замена набора переменных, без перезагрузки.
- Оверлеи закрываются крестиком/повторным нажатием иконки.
- Ленты вкладок: маска затухания появляется только при реальном переполнении и учитывает
  положение прокрутки.

## Ассеты

Внешних изображений нет. Иконки — минимальный inline-SVG (сетка, документ, весы, шестерёнка,
список, солнце/луна). При интеграции заменить на иконки, принятые в кодовой базе (`lucide-react`),
сохранив размер (14–16px) и толщину штриха (1.6–1.8px). Шрифт — Golos Text из Google Fonts.

## Что важно не потерять при верстке

1. Приоритеты P0–P3 — единственный источник цветовых акцентов, кроме основного фиолетового.
2. Стекло только на оверлеях, лежащих над контентом; плоские поверхности — без blur.
3. Обе темы обязательны, значения не «додумывать» — брать из таблиц выше.
4. Мобильная «Очередь» — раздел навигации, а не модальное окно.
